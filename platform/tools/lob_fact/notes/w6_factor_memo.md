## 2. 同 (ms, side, price) 内 sweep 定位：三条实数据根因 → 冻结规则

`lob_events` 与 `lob_sweep_meta` 是**两张表**，`run_lob_batch._fill` 对每张表各自
`seq = range(1, len(rows)+1)` → **两套独立 seq 空间，不可互比**。因此同一毫秒内"行"
与"扫单"的先后**无法从表里直接读**，必须按语义复原——这是 W6 唯一的真实建模难点，
也是本轮 3 个回归的共同根因。

### 2.1 根因 ①：`tail_order` **不是**位置证据（曾据此定位 → 5,798 幻影）

引擎 `_drop_level(side, px, vol_before, tail_oid, ms, ph)` 传的是**队列尾订单 id**：
该 id 的加单行可能位于 ms 中段，而清档发生在 ms 末。实例 `000155.SZ@20260803
ms=34257180`：sweep `vol_before=3200, tail_order=2173022`，但 2173022 的加单行在
该 ms 内、之后还有 `6100→5500→5400→5200→3200` 四笔成交行。按 tail 行绑定 = 把
sweep 插在中段 → 后续成交行把已清的档**复活**（A=3200 / B=none）→ 5,798 幻影级样本。
该 code-day 在上一轮还是 PASS，是本轮改动的直接回归，已用真实数据钉为回归测试
`test_band_fold_same_ms_sweep_position_by_vol_before_not_tail_row_id`。

### 2.2 根因 ②：band 抑制让折叠链**缺行**（曾保留 → 2,048 幻影）

band 限物化会抑制出带档的事件行；当抑制掉的恰是"出带消耗行"时，折叠链上没有**任何**
位置能解释 sweep 的 `vol_before`。实例 `000021.SZ@20260803 B@369100`：
`add 0→2500 (id=1198385, seq=11149)` + `sweep vol_before=2100`；中间 400 股消耗行
在带外被抑制。若此时选择"保留档"，该档成为幻影（B 侧该档已终结，A 侧残留 2500，
随后样本序列 `[2500, 2500, 2500]` vs `[None, None, None]`）。

### 2.3 根因 ③：行前清档 + 同 ms 重建（**不能**一律判终结）

存在合法形：sweep 清空该档（`vol_before` 命中折叠链的**内部**位置 `cs[k]`），紧接着
在同 ms 内有 `prev_vol == 0` 的**重建行**——此时行流末量才是终值，档在。曾把规则写成
"链末不符一律删"，被单测 `test_band_fold_same_ms_chain_rule_sweep_position` case (c)
抓住（`{}` vs 期望 `{100000: 900}`），据此补出内部链位豁免。

### 2.4 冻结规则（`BandFold._apply_key` 终态）

行按 seq 序以**绝对量**施加（`prev_vol != 链现量` → `n_drift_chain++` 并采纳
`new_vol`；`new_vol == 0` → 删档），得链值 `cs[k]`（`cs[0]` = 入段量）；随后逐 sweep：

1. **无行 或 `vol_before == cs[-1]`（链末吻合）** → 该档确被清空 → **终结**（删档）；
2. **命中内部链位 `cs[k]` 且 `rows[k].prev_vol == 0`**（行前清档 + 同 ms 重建）→
   **保留**，终值 = 行流末量；
3. **无任何链位可解释**（2.2 折叠缺行形）→ **仍终结** + `n_same_ms_ambiguous++`。

规则 3 的"仍终结"是**实证选择**，两条独立证据：

- **keep vs del 变体对照**（`/tmp/w6_rule_variants.py`，8 code-day × 1s，只改该分支）：
  仅 `000021.SZ@20260803` 有不可判定样本（62 个），**keep = 2,048 幻影 + 14,226 因子
  失配 + dmax 3.355e5；del = 全 0**；其余 7 个 code-day 两变体全同（无区分）。
- **真值判据**（`/tmp/w6_ambig_classify.py`）：给 B 侧 `_emit`/`_drop_level` 插桩**同一
  全局计数器**（真实事件序，真值），对每个不可判定 case 查"该 ms 该键在 B 侧的最后一条
  是行还是扫单"：**70/70 全部为"扫单在后"（终结），0 例"扫单在前"**
  （62+1+7 = 70，8 code-day 全覆盖）。

`n_same_ms_ambiguous` 与 `n_drift_chain` 是**报告诊断字段，不进闸门**——刻意保留为
"规则此处是推断"的可见计数，而不是假装全知。

回归测试（`tests/test_factor_panel.py`，24 测试全绿；每条都先红后绿）：
`..._same_ms_sweep_position_by_vol_before_not_tail_row_id`（根因①，真实
000155.SZ@20260803 行/sweep）、`..._terminal_sweep_wins_on_unseen_consumption`
（根因②，真实 000021.SZ@20260803）、`..._same_ms_recreate_row_does_not_consume_sweep`
（根因③，合成形）、`..._sweep_terminates_drifted_level_when_no_rows_same_ms`（无行形）。

## 5. 诚实边界（冻结；勿复述为"全簿 100% 精确"）

1. **band 限物化 → 出带漂移**：`drift` = A 折叠视图与 B 全簿在带视图的差异比例，
   实测 **0.85%~5.05%**（8 code-day，最高 000021.SZ@20260803 5.05%）。该漂移在 A/B
   两路**对称**（B 的 shadow 用同一发射律），故 M7 第③项比的是 shadow 视图；**真实
   全簿与 band 视图在边缘档存在差异**，消费方按 band 语义使用（rank ≤ R ∪ δ 对侧 best）。
2. **同 ms 序不可解析**：`lob_events`/`lob_sweep_meta` seq 独立，§2 规则是**推断**。
   本小样 70 例不可判定形全部经 B 侧真值判为"终结"（0 反例），但这是**样本结论**，
   不是全史定理 → `n_same_ms_ambiguous` 永久保留为报告计数；全史批量值见 W5 月 QA。
3. **nq（挂单笔数）口径**：只来自分钟检查点；1s 面板 14,340 样本中仅 195~239 个
   aligned，其余为 `-1`（未知，不插值）。**不要**把 1s 的 nq 列当逐秒真值。
4. **`spread < 0` 共两类，都已定位（面板保留这些行，消费方按 `time_ms` 过滤）**：

   **(a) 收盘集合竞价段（14:57:00~15:00:00）= 该阶段的正确语义，非伪影**：订单簿在
   集合竞价期本就可"交叉"（买单挂高价、卖单挂低价，等单一价撮合），故 `bid_p1/ask_p1`
   是该段订单簿的极值而**不是可成交报价**；同期原始快照只报**单一指示价**（实测
   600036.SH 14:57:10 快照 `bid_p1 = ask_p1 = 402700`，两侧量相等 33900/33900）。
   实测规模：1m 8/956（0.84%，2 行/code，恰为 14:58:00 与 14:59:00）；1s
   713~714/57,360（1.24%，`time_ms ∈ [53,821,000, 53,999,000]`）。剔除该段后
   600036.SH 1m 其余 237 样本价差均值 = **+111.8**。

   **(b) SZ "1.00 元带价市价单"的 Δt 窗口 = 已知代价，非引擎错**（W6 新发现，
   000021.SZ@20260803 的 2 个 1s 样本 `time_ms = 35,353,000/35,354,000`，
   `bid_p1=353500 / ask_p1=10000`）：SZ 逐笔委托里少量 type `'1'`（市价）带
   非零价 `1.00`（该 code-day 48 单：46 个 `'1'` + 2 个 `'U'`，**全 S 侧，全部被
   成交引用全额消耗** traded == volume）。W1 冻结规则 ="按价不按类型：价>0 ⇒ 簿"
   （w1 memo §5 L113）⇒ 该档按 1.00 入簿，因订单报文与成交报文的时戳错位
   （实例 id 12169457：委托 `35,352,110` → 成交 `35,354,400`），期间 **1.00 档
   rank=1 即成 best ask** → 该 ~1 秒内 spread 深度为负。该类**未进闸门也不静默**：
   A/B 两路同规则（M7 0 差异），且可由 `ask_p1 == 10000` 精确识别。
   20250812 同日该类订单 2/6 单（000155/000021），但 Δt 未跨越 1s 采样点 → 0 个交叉样本。
5. **深档（>10 档快照）无外部真值**：事件级构造保真 + M6 重组 + A/B 同位门兜底，
   但**不可**声称深档逐档正确（快照只覆盖 10 档）。
6. **B 侧 SH 未解析成交计数非零为既有事实**（W1 表征的"先成交后报"）：
   `unknown_fill` 600036.SH@20260803 = 185,396 / 600184.SH = 23,750，
   `fill_excess` 13,250 / 2,162，`fill_over_rem` 2,804 / 764，`cancel_excess`
   161 / 209；**SZ 侧全 0**。这些是 taker 侧不入簿的已知形态，**不影响** M7（两路
   发射契约相同、且这些事件不进带内发射）。
7. **小样 ≠ 全史**：本 WS 结论基于 2 日 × 4 code（两所 × 大盘/中盘）；全史 74.5K
   code-day 的通过率与失败分类由 W5 月 QA 汇总给出。
