## 1. δ 滞后分布（消息时戳晚于簿面生效）— 快照残差主因

方法：连续快照对 (S1@t1, S2@t2)（Δt≤30s），对**无撤单/成交触达（add-only）**且两快照同价同档的档位，
Δsnap = v2−v1 与窗内加单 A(t1, t2] 对账；差量按 attrib_lag 前缀恰等归因（window=500ms）。
**档位范围 = 可见 10 档中 rank1-5 双侧**（rank>5 触达频低、rank-shift 噪声高，排除）。
空闲档（无加单且 Δ=0）与 active 分桶；zero_lag 只计 active。

4. **锚定采纳吸收 δ 边界桶；不做任何时戳猜算**（规格 §风险）。M2 门：可归因差量已全分类（zero/over/lag/gt_window/no_exact/触达/档位移），不可分类 = bug。

**结论**：
1. **SZ C 行撤单量恒 == 订单当前剩余（整单全撤，100%/6 天，0 partial/0 excess/0 unknown）**——SZ 撤单 = 整单移除，无部分撤单消息语义；"部分撤单"只发生在同一订单的部分成交之后（C 行量=成交后剩余）。
2. **SH D 行同为全撤剩余量语义**（partial=0；98.5-99.9% full）——双流同构，同一撤单通道。
3. **SH D 偶发 excess（0.14-1.45%）= 撤单量 > 账本剩余**，归因：SH 逐笔成交为**合并打印**（同一时刻单侧多笔连续成交合并，打印行 qty 可为单侧订单剩余的数倍——实证 600184@20260803：买方 762038 单 200 的打印行量 500 = 相邻同价多单合并；~44% 打印行 taker ref 在委托流中无对应 add（先成交后报类，与 W0 一致））→ fills 在账本先 clamp 消费 ≥ 剩余，D 行（真实剩余）后到 → qty>rem。**非引擎错、非上游丢数据；系统桶**。
4. **600036@20251215 SH 全解析日（ref 未知率 0%）**：该日文件形态无先成交后报类 → SH 41-45% 未知率是逐日数据形态差异而非系统常量（W6 因子受限表征按日归因）。

**引擎规则固化**：撤单消费 `min(qty, 剩余)`，幂等；超量/未知/重复 → 桶计数不崩；SZ 整单全撤路径为生产主路径（min 为防御）。

## 3. ref 解析率（撤单/成交双侧）

- **SZ 撤单 ref 100% 解析**（6 天，u_cancel=0；被撤类型分布 `0` 99.6-100% + `U` 少量（1-39 行/日）——U 单的剩余自动撤销走 C 行正常通道 ✓）

- **SH 成交 ref 55.0-57.9% 可解析**（600036@20251215 例外 100%）；不可解析侧 = taker（加单行缺失）。**簿面重建无碍**（taker 本就不进簿），全量订单计数类因子 SH 受限（逐日表征）。

## 6. 2025-09 差行归因（tick_fact orders/trades vs raw）

两样本（000155@20250915、600184@20250915）orders 与 trades 各差恰 1 行（tick 少）：
- 差行 = **09:26:00.000 全零哨兵行**（时间 92600000，价=0、量=0、id=0、委托类型/代码/BS 空、自然日 0；委托与成交文件各 1，两所同构）。
- 归因：tick 转换器 `价=0` 过滤路径丢弃（与 C 行同桶）→ **非数据丢失，批产批次特定哨兵**；2026-08 等其余样本 0 差。
- 呼应：raw 端该行在 streams 中双侧 ref=0 → n_zero_ref=1（两样本各 1）✓ 同一行，链路自洽。
- cancels 表（W0）2025-09 与 raw C 行逐行 0 差（tick_cancels==raw_cancel_rows）✓。

## 8. W2/W3 语义固化清单（由此 memo 直接进引擎与 QA 门）

1. 阶段常量同 config；竞价段 adds 只登 registry（观测），撮合打印（09:25 窗）消费 registry；连续簿从开盘基线（W3 anchoring 注入）启动。
2. 加单入簿规则：`价>0 ⇒ 簿`（SZ 0/'1'/U 与 SH A 同规则；'1'/U 价=0 registry-only）。
3. 撤单通道双所同构：SH D 与 SZ C 同一代码路径；消费 min(qty,剩余)；SZ 生产全整单全撤。
4. 成交按 ref 逐单消费 min(qty,剩余)：SZ 双侧必可解析；SH 未解析侧= taker 不进簿（簿面不动作）；SH excess 桶（合并打印 ref 量>单剩余）系统存在 → M4 桶: unknown_fill/fill_excess/unknown_cancel/cancel_excess 非 0 = SH 常态分类桶，SZ 目标 0。
5. δ 吸收：快照锚定采纳窗 500ms 吸收 ≥99% 滞后；over/no_exact 同窗分类（M2 门）。
6. 开盘硬基线 = 首张连续快照（SZ 09:30:00.000 / SH 09:30:01-02），竞价残留不重建。
7. 测试存根击穿基准：SZ 日事件量 2.1万-66.8万（000021@20260706 标杆：66.8 万委托事件 + 41.8 万成交行 refs）→ W2 引擎吞吐门 <2s/code-day 的实测样本与内存审计样本由此选定（000021@20260706 = 峰值样本）。
