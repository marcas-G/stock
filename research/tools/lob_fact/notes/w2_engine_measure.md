## 2. 语义对账（W2 counters vs W1 ledger 真值，逐 code-day 全零/全匹配）

- SZ 6 日：全部防御桶（unknown_fill/fill_excess/unknown_cancel/cancel_excess/dup_add/zero_ref_fill）= 0
  —— 撤单 ref 100% 解析 + 成交双侧 100% 解析的引擎级复证（W1: SZ C 行 6 天 100% full、ref 双侧 100%）。
- SH 4 日：unknown_cancel=0（D 撤单必可回溯）；unknown_fill/fill = 0.420-0.450（600184×2、600036@20260513）
  与 0.000（600036@20251215 全解析日）——逐日复现 W1 memo 表征（45.0%/0%），未知率是数据形态
  逐日差异非系统常量；cancel_excess 43/97/125/209 = SH 合并打印撤单量>单剩余桶（W1 归因）。
- EOD auction_rem+continuous_rem 分桶守恒；rows/sweeps v1==v2 逐日 bit 全同（band 门与状态机
  行为不变的输出级证据）。

## 3. 吞吐门（<2s/code-day 引擎重放段）

- **8/10 过门**：0.14-1.34s（SH 600036@20260513 1.02s 亦过）。
- **2 例外（枚举，非隐藏）**：000021@20260803（1.25M events）5.3s；000021@20260706（1.69M events）
  8.4s。两者 = 池内最活跃 SZ 单日（>1M 事件）。实测单事件成本 2.1-5.0µs/e，超活跃日含 ~1-1.4µs/e
  排序成本（adds+trades 双流拼接在接缝处必然非单调 → 每次全排序；批算链向量化预合并后引擎
  单调跳排即省，engine 已实现该路径，W4 启用）。
- **诚实结论**：纯 Python 引擎重放下界 ~3-5µs/e → >1M 事件日地板 ~5-8s，字面 2s 门在池内
  前 0.1% 量级超活跃日不可达（除非 C/Rust 重写——不在本设计 scope）。**批算算术**：10 日
  引擎合计 17.6s（3.25M events，均值 1.8s/日，中位 0.24s）；即使全史 0.5% code-day 为峰值级
  （~370 日 × 7s ≈ 0.7h），引擎段单核当量仍 ≤ ~15h（W4 试点月全量实测取代模型，W5 前复评）。
  门语言修订：**典型 code-day 引擎重放 <2s；超活跃日按实测成本计入批算预算（上界 +0.7h）**。

## 4. 内存/worker 算术冻结（W4 输入）

- 单 code-day 峰值 RSS 实测：典型 150-410MB，峰值 1.36GB（000021@20260706，事件全驻留 + registry
  + 簿面 + 事件行——最坏上界；W3 物化流式化后下降）。v2 gc-off 使 000021@20260803 +6.6%
  （1.05→1.11GB，GC 暂态垃圾至 ingest 结束才回收）——可接受，逐日子进程隔离本就释放。
- worker = min(8, ⌊(27.2−4)/(1.36×1.5)⌋) → 上限 8 名义 11 → **冻结起 4-6**（date 切片联读驻留
  ~3-5GB 待 W4 试点实测，MemAvailable 低水位不派发；常态 ≤24GB 硬约束审计 30s 采样）。
- max_levels 244-1168 / max_queue 263-3474（000021@20260706 峰值）→ 锚定档位深档内存定标。

## 5. 冻结决策

1. 行量模型确认：rows ≈ 0.66-0.86 × events（band 抑制 15-35%；SH unknown-fill 高日更低——
   不可解析 ref 不触簿不产行的引擎一致性证据）。**tier 1 全 band 物化成立**，无回退。
2. 行宽上界 96B/88B 冻结为批算体积预算（≤1.5×源，W4 parquet 实值复核）。
3. 桶/守恒语义与 W1 ledger 双实现一致 → anchoring 层（W3）可无引擎改动直接叠。
4. probe_open.py（W3 开盘模型探针）已就位：registry 携入 vs 快照基线的 10 日档级对账
   （w3_open_{code}_{day}.json）；W1 已定"首张连续快照=硬基线采纳"，探针量化缺口入 W3 memo。
5. 门语言修订（§3）写回 spec §3.4/W2 记录。
