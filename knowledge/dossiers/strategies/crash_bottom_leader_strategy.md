## 1. 策略定义（完整规格，v2.0）

| 层 | 规则 | 参数 | 验证状态 |
|----|------|------|---------|
| **市场状态** | 中证1000 指数 20 日累计收益 < -8% → 触发；恢复 → 空仓 | 阈值 -8%，窗口 20 日 | ✓ -6% 证伪（浅触发噪声） |
| **入场缓冲** | 触发段首周空仓，第 2 周起入场 | — | ✓ 年化 +15pp |
| **选股** | 触发周按 signal（超跌秩+龙头秩）降序取 top K，等权 | **K = 30**（v2.0 从 20 升级） | ✓ K=10/20/30 单调、40 见顶 |
| **调仓** | **周频**（周五对齐）按最新信号全换 | — | ✓ 必要机制（轮动是 alpha） |
| **可交易性** | 买入日跌停（pct_chg <= -9.8%）排除 | 硬约束 | ✓ 年化 +20pp |
| **成本** | 每笔成交按成交额×cost_bps（买/卖各一次；段界清仓与新段再建仓各计一次） | 35bps = 佣金 2.5×2 + 印花税 5 + 冲击 10×2（往返综合校准） | ✓ C2：段界成本已计（历史口径漏计，旧值为低估） |
| **退出** | 掩码恢复 0 自动清仓；空仓期收益 0 | — | — |

**策略本质**：信号驱动的轮动捕捉——每周换入"当下最被错杀的大票"，吃
超跌反弹的周切片。不是"持有优质标的"（止盈止损/长持有期均证伪）。

## 2. 回测结果（v2.0：K=30 + 段首缓冲 + 跌停过滤 + 成本 35bps）

> 历史快照（2026-08-18，不可复现条件见文首状态块）；且产自 C1/C2 修复前的代码 ——
> 跌停过滤当时静默失效、段界清仓成本当时未计，以下数字为**低估**口径旧值。

| 指标 | 值 |
|------|----|
| 触发周 | 109（11.5 年，空仓 86% 时间） |
| 累计净值 | **3.51**（2015-06 起） |
| 触发期年化（口径见下） | **81.9%** |
| **全期年化**（含空仓期） | **11.5%** |
| 触发期夏普 | **1.86** |
| 最大回撤（真实路径） | 15.0%（蒙特卡洛典型 30-38%，见 §3） |
| 总成本 | 19.0%（累计） |
| 平均换手 | ~50%/调仓周 |

> **口径说明**：81.9% 是"触发期年化"（109 触发周/52 ≈ 2.1 年复利，空仓期
> 不参与）。资金全年占用视角的全期年化 = 3.51^(1/11.5) - 1 = **11.5%**。
> 策略定位：**危机应对层**（用钱时赚得快），不是全天候主策略。

### v1.1 → v2.0：K 升级效果

| 配置 | 触发期年化 | 夏普 | 回撤 |
|------|-----------|------|------|
| v1.1（K=20） | 72.3% | 1.59 | 16.2% |
| **v2.0（K=30）** | **81.9%** | **1.86** | **15.0%** |

机制：超跌反弹信号在 top-30 区间仍有效，等权 30 只的分散降低单票波动
（回撤反而更小），轮动捕捉面更广。

## 3. 蒙特卡洛模拟（bootstrap，1000 条路径）

采样单元：33 个触发段（block bootstrap，保留段内序列相关）。真实路径与
模拟分布对比（v1.1 分布，v2.0 真实路径数值近似）：

| 指标 | 真实路径 | 模拟 p5 | p50 | p95 |
|------|---------|---------|-----|-----|
| 触发期年化 | ~82% | 32.3% | **75.2%** | 137.9% |
| 全期年化 | ~11.5% | 5.2% | **10.8%** | 17.1% |
| 夏普 | ~1.9 | 0.77 | **1.69** | 3.40 |
| 最大回撤 | ~15% | 11.7% | **37.6%** | 38.0% |

**三个结论**：

1. **收益特征稳健**：真实触发期年化落在 bootstrap 中位数附近——不是运气。
2. **全期年化 ~11% 是定位真相**：危机应对层（触发期 75-82% 年化），
   不是全天候主策略（空仓 86% 摊薄）。
3. **真实回撤 15% 是段序运气**：典型路径回撤 30-38%（74% 概率 >30%）。

## 4. 探索史（已评估变异汇总）

| 变异 | 验证结果 |
|------|---------|
| 跌停过滤 | ✓ 年化 +20pp（不可交易股是纸面诱饵） |
| 段首缓冲 | ✓ 年化 +15pp（时间过滤胜幅度过滤） |
| **K=30** | ✓ 年化 +9.6pp（本策略唯一参数升级） |
| 超跌窗口 dd250 / mom10 | ✗ 20 日是时效性平衡点 |
| 稳健成分 / 市值+成交额叠加 | ✗ 触发期成分须与超跌正交 |
| 强度分级仓位（深跌重仓） | ✗ 深度与反弹非线性 |
| 组合级止损 10-20% | ✗ 误杀 2015 盈利段 |
| 固定周期降频（2/4 周） | ✗ 错过轮动 |
| 止盈止损规则 + 买入门槛 | ✗ 止盈截断右尾、锁死轮动 |
| 触发阈值 -6% | ✗ 浅触发噪声主导 |
| 分批左侧 + 持有到修复（--long） | ✗ 掩码是 alpha 开关：中性段持仓无 alpha，全期 7.3% < 周频 11.5% |
| 知乎"死等股灾"战法（原样实现） | ✗ NAV 0.923（-0.7%/年）：1-2 日快速止盈吃不到数周尺度的反弹、10% 止损在波动期慢性失血（38 次交易） |

**沉淀经验**：时间过滤 > 幅度过滤；轮动是超跌反弹的 alpha 来源（周频不可
替代）；触发阈值是质量门槛不是频率调节器；**掩码是 alpha 开关**——超跌
反弹的 alpha 只在 -8% 以下触发区存在，任何把持仓延长到 alpha 区外的设计
（止盈/长持有到修复）都会稀释收益。全期收益上限 = alpha 区持仓占比 ×
alpha 收益（当前 18% × 82% ≈ 11.5%）——突破需双引擎（常态层 + 危机层）。

### 外部方法论对照：知乎"死等股灾"战法（`tools/strategies/strategy_wait_crash.py`）

用户提供的知乎战法（空仓等恐慌、金字塔分批、1-2 日快速止盈、10% 硬止损、
科技/半导体 ETF 标的）**原样实现**（半导体行业 197 股等权代理 ETF，000300
代理上证，触发=月线跌 6%+反弹 1.5%+缩量 0.9）：NAV 0.923、-0.7%/年、38 次
交易。**与本文策略的差异根因**：

| 维度 | 知乎战法 | 本策略 v2.0 |
|------|---------|-------------|
| 持有 | 1-2 日快速止盈（吃不到数周尺度的反弹） | 周频轮动吃到反弹全程 |
| 止损 | 10% 硬止损（2015 熔断期反复触发=慢性失血） | 无止损（掩码退出，时间过滤） |
| 标的 | 单一板块（半导体 2015-2018 长期阴跌） | 全市场超跌龙头 top-30 |

方法论一致处（空仓等待、纪律、分批）与本文验证一致；**参数层（止盈/止损
时机）被数据证伪**——印证"时间过滤优于幅度过滤"与"轮动是反弹 alpha"。

## 5. 局限与下一步

- **冲击成本低估**：35bps 在股灾流动性枯竭期可能偏低（跌停过滤已部分对冲）。
- **空仓资金未计收益**：全期年化 11.5% 未含空仓期货基/逆回购（+1-2pp）。
- **组合定位**：作为危机层与主策略组合的全期贡献需组合级验证。
- **K>30 边界**：40 与 30 持平——30-40 之间未细扫（避免参数搜索）。
