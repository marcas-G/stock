## 关键决策

1. **日频信号 + 分钟执行**：信号仍 EOD 产出；成交挪到次日分钟窗口（默认 `[0,30]`，VWAP，参与率 10%）。
2. **全可配**：执行窗口、价格口径（vwap/open/close/twap/mid）、分批切片、参与率、**价格触发**（limit / vwap_offset）、兜底（none/close）。
3. **尽量模拟真实**：一字涨跌停不成交、停牌跳过、参与率上限 + 未成顺延、限价未触发不成交（默认）、成本叠加滑点。
4. **向后兼容**：默认 `NEXT_OPEN` 逐值不变；`NEXT_CLOSE` 的 7 处显式拒绝保持不动。
5. **V1 边界**：量能触发（V2）、分钟 NAV（V2）、盘中临停规则库（另立）；tick 不参与。

## 验收锚点

- `NEXT_OPEN` 回归零差异；配置非法全部 fail fast；
- 小样本手算对拍（VWAP/限价/参与率顺延/部分成交/兜底各一例）；
- 一字板/停牌/未触发不成交；持久化 round-trip；
- CH 端到端（20 只 × 1 个月）+ 全门绿（`make gates`，pytest ≥ 2570/13）。
