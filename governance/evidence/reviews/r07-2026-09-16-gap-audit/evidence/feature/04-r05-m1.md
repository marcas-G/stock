## 判定

- **R05-M1 本体（最小发现入口）已闭环**：CLI 两条腿（`op list --catalog` / `op doc` 回退）
  可用，528 条可检索；R06 复查（44 passed / 528 条）与本审计一致。
- **完整同源（E2/A7）开放**：分类面未进入 `catalog dump` JSON / `catalog.md` 正文，
  即"文档同源"（design §9-G8）未达成；interface.md 已明确标注归 Plan 2。
- 缺口清单（`--catalog` 之外还缺什么）：
  1. 分类面无 docstring/参数签名/档案（`op doc` 只回元数据，未注册项无说明）；
  2. catalog JSON/正文无分类面 → 写因子的 AI 无法从活文档检索"能写什么"；
  3. 分类面与注册面的一致性巡检（orphan/不可用标注，如 A10 scipy 缺依赖）无门。

## 用户影响

- 能用 CLI 发现分类面（缓解了大部分）；但"文档防漂移"承诺（catalog 由分类元数据生成）
  未兑现——读 `catalog.md` 的人/模型会低估可用算子面（doc 里只有注册面）。
- 不可用算子（scipy 缺依赖、window=None REF 族）在分类面/文档中与正常算子无差别。
