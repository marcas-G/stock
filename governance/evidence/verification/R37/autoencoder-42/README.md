## 结论

AE ≈ PCA（无非线性增量），低于等权秩与 PLS(1)；**不建议引入 AE 聚合**；PLS(1) 值得作为
下一候选（t 最高、增量最大、换手最低）。零假设探针 ≈0，装配/评估链无隐性泄漏。
